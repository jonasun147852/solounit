# 经典时间环判定 SAT：Lean 4 形式化

文件：`CTC.lean`（342 行，纯核心 Lean 4.35.0，不依赖 Mathlib）

编译命令：`lean CTC.lean`
结果：0 错误，0 警告，四个主定理的公理依赖均为 `[propext, Quot.sound]`，无 `sorryAx`。

## 模型

- 状态空间 `Fin N`，N 个候选赋值。
- 一次穿环的动力学 `step φ x = if φ x then x else x+1 (mod N)`：
  满足公式就原样送回，否则换下一个。
- Deutsch 自洽条件 `Stationary f w`：对每个状态 y，`w y = Σ_{x : f x = y} w x`，
  即流出环的质量等于流回环的质量。

## 已证定理

| 名称 | 内容 |
|---|---|
| `ctc_reads_sat` | 若 φ 可满足，则任何自洽历史中权重为正的状态都满足 φ |
| `ctc_decides_sat` | 读任何自洽历史的任何正权重状态 y，`φ y = true` 当且仅当 φ 可满足 |
| `stationary_exists` | 对任何 φ，总存在一个总质量为正的自洽历史（环里总有东西可读） |
| `ctc_decides_cnf` | 上述结论对具体的 CNF 公式（n 个变量，状态空间 `Fin (2^n)`）成立 |
| `cnf_history_exists` | 具体 CNF 情形下自洽历史存在 |

## 证明思路

1. 自洽性蕴含"向后封闭"：权重为正的状态一定有一个权重为正的前驱（`backward`）。
2. 流入不满足状态的只能来自不满足状态，且只能经由循环后继（`step_of_unsat`）。
3. 从一个不满足的正权重状态向后走 N 步，得到 N 个连续的不满足状态（`chain`）。
4. N 个连续循环步覆盖全部状态（`cover`），于是所有状态都不满足，与可满足性矛盾。

## 没有证的部分（诚实边界）

- 未定义电路模型，因此未在 Lean 里陈述"每次穿环是多项式规模电路"。
  这一点在定义 `cnfStep` 的层面上是显然的（求值 CNF 加一次自增），但没有形式化资源计量。
- 只做了经典（概率）版本，没有做 Deutsch 的量子版本（密度矩阵的不动点）。
- 只证了 NP ⊆ P_CTC 方向的核心引理，没有证 P_CTC ⊆ PSPACE 的上界。
- 没有涉及 Bennett 等人对 Deutsch 模型物理合理性的质疑，那不是数学问题。
